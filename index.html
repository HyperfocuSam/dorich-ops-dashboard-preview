關於這個原型

五大模組全部喺度，數字係示範用，接上真實數據源之後會自動換成真數。
  • 立體效果係真 3D（WebGL / Three.js），唔係圖片。背景嗰個線框結構會隨滑鼠輕微轉動；如果部機唔支援 WebGL，會自動退返做純深色底，唔會爛。
  • 呢個效果要用自訂網頁（custom web app）先做到，Looker Studio 做唔到：佢冇 report-level 嘅 custom CSS / JavaScript，內置嘅 Gauge 係橫向長條而唔係圓形錶。呢點要喺開工之前決定清楚。
  • 深藍底 + 橙色係 DoRich 自己網站嘅語言 — dorich.co 個 nav bar 就係深色底配橙色 logo。
  • 報名漏斗已修正建議書入面嘅重複計算；圖表配色經色盲模擬驗證，每段直接標數，唔單靠顏色分辨。
